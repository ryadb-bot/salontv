# Salon TV

Application IPTV pour Fire TV, en test dans la famille.

## Installer

1. Sur la Fire TV, installez **Downloader** depuis la boutique Amazon.
2. Paramètres › Ma Fire TV › Options pour les développeurs › Installer des applis inconnues › **Downloader** : activé.
3. Dans Downloader, saisissez l'adresse :
   `https://github.com/ryadb-bot/salontv/releases/latest/download/SalonTV.apk`
4. Installez, ouvrez Salon TV et connectez-vous avec vos identifiants IPTV.

Les mises à jour se proposent ensuite toutes seules à l'ouverture de l'app.
